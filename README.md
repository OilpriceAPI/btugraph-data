# BTU Graph data

Versioned, machine-readable snapshots of the [BTU Graph](https://btugraph.com/) energy company knowledge graph. The dataset connects energy companies, sectors, capabilities, markets, regions, workflows, software products, market-data requirements, and operational decisions.

The canonical dataset page is [btugraph.com/data](https://btugraph.com/data/). Entity URLs in the exports point to the corresponding canonical BTU Graph profiles.

## Current snapshot

- Access: no authentication required
- Formats: JSON, CSV, and OpenAPI 3.1

| File | Description | Canonical live source |
|---|---|---|
| [`data/graph.json`](data/graph.json) | Full typed graph, provenance, data dictionary, and evidence links | [`/graph.json`](https://btugraph.com/graph.json) |
| [`data/companies.csv`](data/companies.csv) | Flat company directory for analysis and spreadsheets | [`/companies.csv`](https://btugraph.com/companies.csv) |
| [`data/openapi.json`](data/openapi.json) | OpenAPI description of all public BTU Graph data endpoints | [`/openapi.json`](https://btugraph.com/openapi.json) |
| [`data/metadata.json`](data/metadata.json) | Snapshot identity, counts, source endpoints, and SHA-256 digests | Generated from the files above |
| [`SHA256SUMS`](SHA256SUMS) | Integrity manifest for the snapshot | Generated by the sync script |

## Quick start

Download the current repository snapshot:

```bash
curl -O https://raw.githubusercontent.com/OilpriceAPI/btugraph-data/main/data/graph.json
```

List companies associated with commodity trading and origination:

```bash
jq -r '
  .edges[]
  | select(.relationship == "has_capability" and .to == "capability:commodity-trading-origination")
  | .from
' data/graph.json
```

Run the dependency-free examples:

```bash
npm run example:javascript
npm run example:python
```

See [`docs/DATA_DICTIONARY.md`](docs/DATA_DICTIONARY.md) for the model and [`docs/QUERIES.md`](docs/QUERIES.md) for more examples.

## Provenance and editorial method

BTU Graph compiles public evidence into source-reviewed entity records and editorial relationship classifications. Company nodes include the public sources used during review. A `lastReviewed` date means the cited evidence was checked on that date; it is not a real-time status guarantee.

- [Methodology](https://btugraph.com/methodology/)
- [Canonical data page](https://btugraph.com/data/)
- [Company directory](https://btugraph.com/companies/)
- [Corrections](https://btugraph.com/corrections/)

## Releases and updates

Git tags and GitHub releases identify immutable editions. A scheduled workflow checks the canonical exports weekly and opens a pull request only when the source data changes. Every change must pass the same integrity checks as a local sync.

To refresh a working copy from the canonical endpoints:

```bash
npm run sync
```
