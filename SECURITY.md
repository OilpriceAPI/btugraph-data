# Security policy

This repository contains public static data and dependency-free examples. Do not report factual data corrections as security issues; use the [BTU Graph correction process](https://btugraph.com/corrections/).

Report a security concern privately through [GitHub's repository security advisory form](https://github.com/OilpriceAPI/btugraph-data/security/advisories/new). Do not include secrets or personal data in a public issue.
